# Portfolio

A responsive portfolio built with React, TypeScript, and Vite.

Includes a persistent light/dark theme toggle and CSS-built interface previews for the sample Taskflow, Ticketboard, and PhishGuard projects.

## Run locally

```bash
npm install
npm run dev
```

## Personalize

- Update `profile` in `src/App.tsx` with your email, GitHub URL, and LinkedIn URL. The name is set to Srinivas.
- Replace the sample `projects` and `skills` arrays in `src/App.tsx` with your own work and skills. The About section currently describes a CSE graduate from SASTRA University and a web developer.
- Adjust the page title and description in `index.html`.

The contact button opens the visitor’s email app with a prefilled subject. The visual project cards currently use CSS artwork, so you can keep them as-is or replace them with project screenshots later.
